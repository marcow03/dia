# 010: Installable PWA

## Decision
The editor is a Progressive Web App built with `vite-plugin-pwa`:
- A web app manifest (name, icons including a maskable one, `standalone` display) makes it installable.
- File handlers register `.typ`, `.tex` and `.drawio`. Files opened with the installed app arrive through `launchQueue` and go through the normal import path.
- A Workbox service worker pre-caches the app shell and all WASM (dia-core and the typst.ts compiler and renderer, ~31 MB). The Typst fonts fetched from jsDelivr are cached on first use. After one online visit the editor works fully offline.
- `registerType: 'autoUpdate'`: a new deploy replaces the cached version on the next load.

## Consequences
- The first visit downloads ~31 MB, mostly the Typst compiler.
- Icons are generated PNGs in `editor/public/` (rendered from the favicon glyph).
