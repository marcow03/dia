# 007: UI principles

- **Few, calm surfaces.** A floating toolbar at the bottom, a document bar at the top left (file actions, export and recents sit behind its menu button), and a style panel that only appears when something is selected. White panels, soft shadows, one accent colour (`#0a84ff`) and the system font.
- **Direct manipulation.** Drag to create, move or resize. While moving, edges and centres snap to other shapes and a guide line shows the match. While creating or resizing, width and height snap to those of other shapes, and dimension marks show every shape with the same size. With several shapes selected, the panel offers align, equal gaps and same width/height. A Layer row and ⌘[ / ⌘] (with ⇧ to go all the way) change the stacking order, which is also the order in the exported files. Arrows snap to shapes and stay bound to them; near a shape its 8 anchors appear and an end within 10 px snaps to one. Dragging the midpoint dot of a segment adds a waypoint. Everything snaps to a 0.25 cm grid.
- **Groups and rotation.** ⌘G groups the selection, ⇧⌘G ungroups; clicking any member selects the whole group (dashed outline). The round handle above a selection rotates it (snaps to 15° near multiples or with ⇧); the panel also takes an exact angle.
- **Movable labels.** A selected element's label shows a dashed handle. Drag it to move the label inside a shape or along a line; it snaps back to the centre line, and Center in the panel resets it.
- **Typst everywhere.** Double-click a shape or line to edit its label. The editor (CodeMirror 6 with a small Typst tokenizer, monospace, auto-indent, auto-closing `$ ( [ { "`) opens just below the element while the label re-renders live in place. Enter adds a line (plain-markup lines get Typst `\` breaks on save), Tab inserts a tab, ⌘Enter saves, Esc cancels. An optional vim mode (`@replit/codemirror-vim`, `:w` / `:q`) is toggled in Settings (⌘,), which also sets the defaults for new elements. The CeTZ code view (⇧C) is a modal like Settings, uses the same editor and closes after Copy. The Text/Label section sets left, centre or right alignment (default left). A text element's box always fits the rendered text, growing while typing and when font, size or weight change. Double-click the empty canvas to write free text.
- **Keyboard first.** V R O D L A T for tools and I for an image (shown under each toolbar button). ⌘S exports CeTZ, ⇧C toggles the code panel. Arrows or hjkl move the selection by one grid step (⇧: one screen pixel); ⌃⇧ + arrows/hjkl selects the nearest object in that direction (plain ⌃ + arrows switch desktops on macOS). hjkl only act as arrows while something is selected, so H and L stay tool keys otherwise. ⌘Z / ⇧⌘Z, ⌘C / ⌘V / ⌘D, ⌘S to save as CeTZ, Enter to edit a label, H (hand), Space or the middle mouse button to pan, pinch or ⌘ + scroll to zoom, ⌘+ / ⌘− / ⌘0 and ⇧1 to fit. Zoom controls sit at the bottom left.
- **Controls appear with the tool.** Picking a tool shows its style panel right away, docked at the top right. Stroke, fill, width and dash are shared by all shape tools. Text settings are tracked twice: once for labels (shapes and lines) and once for the text tool. Arrowheads and corner radius stay per tool. The panel is grouped as Layer, Arrange, Stroke (incl. corner radius), Fill, Arrows, Label/Text. Defaults are remembered across sessions. All controls are custom (no native selects or spinners), so they look the same everywhere.
- **Image export.** Export also offers SVG, PNG and JPEG. The SVG is a copy of the rendered canvas elements (no selection overlays, Typst labels inlined), cropped to the diagram with a 0.5 cm margin and sized in cm; PNG/JPEG rasterise it at 3× 96 dpi (JPEG on white).
- **Escape resets.** Esc deselects everything, returns to the select tool and closes the menu, code panel, style panel and any open picker. While editing a label, the first Esc cancels the edit.
- **No modes to remember.** After creating a shape or arrow, the tool returns to select. Work autosaves in the browser (see 009).
