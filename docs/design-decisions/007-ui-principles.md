# 007: UI principles

- **Few, calm surfaces.** A floating toolbar at the bottom, a document bar at the top, and a style panel that only appears when something is selected. White panels, soft shadows, one accent colour (`#0a84ff`) and the system font.
- **Direct manipulation.** Drag to create, move or resize. Arrows snap to shapes and stay bound to them. Dragging the midpoint dot of a segment adds a waypoint. Everything snaps to a 0.25 cm grid.
- **Typst everywhere.** Double-click a shape or line to edit its label as Typst. Double-click the empty canvas to write free text.
- **Keyboard first.** V R O D A T for tools. ⌘Z / ⇧⌘Z, ⌘C / ⌘V / ⌘D, ⌘S to save as CeTZ, arrow keys to nudge, Enter to edit a label, Space or the middle mouse button to pan, ⌘/pinch + scroll to zoom.
- **No modes to remember.** After creating a shape or arrow, the tool returns to select. Work autosaves to localStorage.
